# Capstone Project - Blog Application

A full-stack blog application built with Node.js, Express, and React.

## Project Structure

```
Capstone project/
├── backend/           # Node.js/Express API server
└── blogFrontend/      # React frontend application
```

## Folders

### Backend
- REST APIs for user management, articles, and authentication
- MongoDB database integration
- JWT authentication
- Image upload functionality with Cloudinary

### Blog Frontend
- React-based user interface
- User authentication and authorization
- Article creation, editing, and reading
- Role-based access (User, Author, Admin)

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd blogFrontend
npm install
npm run dev
```

## Features

- **User Management**: User registration and authentication
- **Article Management**: Create, read, update, and delete articles
- **Role-Based Access**: Different permissions for Users, Authors, and Admins
- **Image Upload**: Upload and manage images using Cloudinary
